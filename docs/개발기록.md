# An Unexpected Adventure — 개발 기록

- 게임: https://woochanj.github.io/AnUnexpectedAdventure/
- 저장소: https://github.com/woochanj/AnUnexpectedAdventure
- 기록일: 2026-11-05

예전 Phaser RPG 저장소를 **탐험 여행 테마의 로그라이크 덱빌딩 웹게임**으로 새로 만들었다.
게임 구조는 슬레이 더 스파이어 계열이고, 화면은 밝은 하이비트 픽셀 아트다.
가장 중요한 건 전투 손맛이다.

---

## 1. 기술 구성

| 항목 | 내용 |
|---|---|
| 엔진 | React 19 + TypeScript + Vite 7 (Phaser에서 교체) |
| 이펙트 | [pixelfx](https://github.com/patch-gg/pixelfx): 픽셀 이펙트 라이브러리 (베기, 폭발, 번개, 숫자 등) |
| 폰트 | Galmuri (한글 픽셀 폰트, OFL) |
| 효과음 | Web Audio로 직접 합성 (소리 파일 없음) |
| 저장 | 브라우저 localStorage (`aua-run-v4`) |
| 배포 | `main`에 푸시하면 GitHub Actions가 GitHub Pages로 자동 배포 |
| 밸런스 | `scripts/sim.ts`: 자동 플레이 봇이 직업마다 수백 판을 돌려 승률을 잰다 |

```
src/game/   게임 규칙 (화면과 분리)
  cards.ts      카드 정의·강화·설명
  combat.ts     전투 엔진 (연출용 신호 cue/fx를 내보냄)
  run.ts        진행·보상·상점·사건 (리듀서)
  map.ts        지도 생성 (아래→위 갈림길)
  enemies.ts    적·지역별 조우
  events.ts     사건·랜덤 인카운터·모렐 이야기
  relics.ts     유물
  story.ts      프롤로그·지역 독백·보스 대사·졸개 대사·엔딩
src/ui/     화면
  CombatScreen  전투 화면, 타격감(히트스톱·흔들림·돌진)
  FxCanvas      pixelfx 이펙트·피해 숫자
  vfx.ts        카드·적·속성별 이펙트 표
  heroMoves.ts  카드별 주인공 동작
  monsterMoves  몬스터 공격·사망 동작
  DragArrow / ChargeFx  카드 끌기 화살표, 카드 집을 때 기운
  Dialogue.tsx  이야기 대화창
  UpdateBanner  새 버전 알림
```

## 2. 게임 구성

### 직업 (외형은 직업마다 대표 하나)

| 직업 | 외형 | 체력 | 치명타 | 특징 |
|---|---|---|---|---|
| 기사 | 모험가 (rvros) | 80 | 10% | 방어도·힘, 내려찍기 |
| 마법사 | 물 사제 (chierit) | 72 | 10% | 원거리 주문, 냉기·화상 |
| 도적 | 바람 암살자 (chierit) | 72 | 20% | 연타·독·마무리 |

### 탐험 구조
- 탐험마다 여섯 지역 중 세 곳이 무작위로 정해진다: 잠긴 동굴, 안개 묘지, 노을 성채, 버섯 숲, 사막 유적, 얼음 협곡.
- **세로 지도**: 아래(시작)에서 위(보스)로 올라간다. 층마다 방이 2~4개다.
  - 위로 나아가거나 같은 층에서 옆방으로 길을 갈아탈 수 있다. 아래로는 돌아갈 수 없다.
  - 모바일 세로 화면에 맞췄다.
- 방 종류: 적, 강적, 사건, 모닥불(휴식·강화), 보물, 상인, 보스.
- **랜덤 인카운터**: 이동 중 14% 확률로 길에서 사건이 생긴다. 끝나면 원래 가던 방으로 들어간다.
  - 매복
  - 떠돌이 행상
  - 보물 고블린
  - 지친 여행자
  - 길가의 사당

### 카드
- 등급은 기본, 일반, 고급, 희귀, 유니크. 레벨은 Lv.1~3이다.
  - Lv.3은 수치가 30% 오른다.
  - 숫자가 없는 카드는 Lv.3에서 코스트가 1 준다.
- 강화하기 전에 확인 창이 뜬다. 코스트가 줄어든 카드는 마나 수정이 초록색이다.
- 지금 카드는 80장이다: 직업 카드, 공용, 연계 24장, 궁극기 6장, 저주.
- **연계(콤보)**
  - "연계 N"으로 이번 턴에 낸 카드 수를 보여준다.
  - 지금 내면 연계가 붙는 카드는 주황색으로 빛난다.
  - 연계 효과:
    - 앞서 낸 카드 1장당 피해 +
    - 직전 카드가 공격(또는 기술)이면 추가 효과
    - 방어도만큼 피해
    - 냉기 산산조각
    - 마무리 일격(이번 턴에 낸 공격 수만큼)
    - 상태이상이 걸린 대상에게 추가 피해
    - 독·화상 즉시 폭발
- **상태이상**
  - 힘, 취약, 약화, 독, 가시, 재생, 활력
  - 냉기: 3 이상 쌓이면 적이 한 번 얼어서 쉰다.
  - 화상: 피해를 준 뒤 절반으로 줄어든다.
- **강한 기술 16장**: 0.65초 동안 기를 모은다. 속성 색 기운이 모이고, 화면이 어두워지고, 상승음이 난다.
- **궁극기 6장** (유니크, 쓰면 그 전투에서 소멸)

  | 직업 | 궁극기 |
  |---|---|
  | 기사 | 거신의 일격, 최후의 맹세 |
  | 마법사 | 운석 낙하, 절대 영도 |
  | 도적 | 천 개의 칼날, 죽음의 낙인 |

  - 기를 더 길게 모은다.
  - 영화처럼 위아래에 검은 띠가 내려온다.
  - 기술 이름이 화면을 가로지른다.
  - 빛기둥과 마법진이 나온다.
  - 카드 테두리가 금빛·분홍으로 일렁인다.

### 적
- 그린 몬스터와 스프라이트 몬스터(LuizMelo, SpritePilot CC0)가 지역별로 나온다.
- **정예·보스 성향**: 만날 때마다 무작위로 하나가 붙는다.
  - 광폭한(힘)
  - 단단한(체력 +30%)
  - 가시 돋친
  - 되살아나는(재생)
  - 맹독의(공격할 때마다 독)
- 특수 행동:
  - 흡혈: 입힌 피해만큼 회복
  - 저주: 낼 수 없는 카드를 덱에 섞음
  - 보스는 체력이 절반 아래로 떨어지면 분노해 힘을 얻음
- 보스: 익사한 기사 → 감시자의 눈 → 끝없는 그림자.

### 유물·운영
- **보스 보상은 보스 유물 3개 중 1개 고르기**

  | 유물 | 효과 | 대가 |
  |---|---|---|
  | 꺼지지 않는 불씨 | 최대 에너지 +1 | 최대 체력 −10 |
  | 저주받은 왕관 | 최대 에너지 +1 | 보상 카드 2장 |
  | 녹슨 모래시계 | 최대 에너지 +1 | 첫 턴 2장 덜 뽑음 |
  | 피의 성배 | 최대 에너지 +1 | 모닥불 회복 불가 |
  | 전쟁 깃발 | 전투 시작 시 힘 +2 | — |
  | 현자의 책 | 매 턴 1장 더 뽑음 | — |
  | 불사조 깃털 | 한 번 부활 | 쓰면 사라짐 |

- **마나의 샘** (사건): 두 번째 지역부터 가끔 나온다. 최대 체력 −12와 맞바꿔 최대 에너지 +1.
- **상점**: 카드 5장, 카드 제거, 유물 한 점을 판다.

### 이야기
- 배경: 세계 지도의 가장자리가 **끝없는 그림자**에 먹혀 지워지고 있다. 주인공은 그 땅을 다시 그려 오는 탐험대다.
- 구성:
  - 프롤로그: 직업마다 동기가 다르다.
  - 지역 도착 독백 6종
  - 보스 등장 대사와 처치 대사
  - 직업별 에필로그
- **지도 제작자 모렐**: 지역마다 한 번씩 다시 만난다.
  - 첫 만남의 선택(구해 줌 / 지도를 뺏음 / 지나침)에 따라 다음 만남이 달라진다.
  - 결과는 도움, 화해, 결투로 갈리고 마지막 장의 보상도 달라진다.
- **졸개 대사**: 전투 시작, 공격할 때, 맞을 때, 쓰러질 때 몬스터 종류별로 말풍선이 뜬다.
- 대화창:
  - 지역 배경 위에 초상화와 이름이 나온다.
  - 글자가 한 자씩 써진다.
  - 클릭이나 Enter로 넘기고, 건너뛰기를 누르면 장면 전체를 넘긴다.

## 3. 전투 연출 (손맛)

**카드 내기 (하스스톤 방식)**
- 대상이 필요한 카드를 끌면 픽셀 화살표가 나온다.
  - 구슬이 흐르고 화살촉은 8방향이다.
  - 화살 색은 카드 속성을 따른다.
  - 겨눈 적 발밑에 고리와 조준선이 생긴다.
- 적이 하나여도 직접 겨눈다.
- 방어처럼 대상이 없는 카드는 위로 끌어 올려 놓는다. 끄는 동안 주인공이 빛난다.
- 카드를 집으면 속성별 기운이 모인다: 화염 불씨, 냉기, 번개, 독 거품, 비전 룬, 칼날 번쩍임.

**타격감**
- 히트스톱으로 맞는 순간 잠깐 멈춘다.
- 피해량에 비례해 화면이 흔들린다.
- 주인공이 맞으면 붉게 번쩍이며 밀려나고, 화면 가장자리가 붉어진다.
- 피해 숫자는 큰 픽셀 숫자로 머리 위에 뜨고 살짝 투명하다.
- 치명타 숫자는 몬스터를 가리지 않게 비켜서 뜬다.

**주인공 동작 (카드마다 고유)**
- 몸 움직임은 다섯 가지다.
  - 돌진
  - 뛰어올라 내려찍기
  - 낮게 미끄러지며 찌르기
  - 사라졌다 적 앞에 나타나기
  - 제자리 시전
- 움직일 때는 예비동작 → 가속 → 미끄러지듯 멈춤 → 천천히 복귀 순서로 감속·가속을 준다.
- 직업별 이펙트:
  - 기사: 금빛 칼날 궤적, 내려찍기 때 집중선·햇살·지면 충격파, 금빛 잔상
  - 마법사(물 사제): 물의 마법진, 물방울, 물줄기·물보라, 큰 주문은 파도
  - 도적(바람 암살자): 청록 잔상, 바람 회오리 베기, X자 바람 칼날, 돌풍

**몬스터 동작**
- 공격:
  - 슬라임류는 뛰어들기
  - 날짐승은 급강하
  - 덩치는 돌진
  - 연타형은 붙어서 연타
- 사망:
  - 크게 맞으면 날아감
  - 유령은 깜박이며 떠오름
  - 슬라임은 녹아내림
  - 해골은 무너짐
  - 나머지는 뒤로 넘어짐
- 몬스터 종류마다 타격 이펙트가 다르다: 할퀴기, 산성, 물보라, 생명 흡수, 둔기, 폭발, 포자.
- 마지막 적이 다 쓰러진 뒤에 전리품 창이 뜬다.

**효과음**
- 카드, 베기, 주문, 타격, 치명타, 방어, 회복, 독, 사망, 승패, 코인, 강화, 이동, 속성별 기 모으기.
- 상단바 ♪ 버튼으로 켜고 끈다.

## 4. 화면·UI

- 하이비트 밝은 픽셀 배경이 지역마다 따로 그려지고, 꽃잎·오로라·반딧불 같은 분위기 이펙트가 있다.
- 하스스톤을 참고한 요소:
  - 붉은 체력 보석과 금테 체력 줄
  - 방패 모양 방어도 보석
  - 육각 마나 수정 코스트
  - 마나 수정 줄
  - 낼 수 있는 카드는 초록 테두리
  - 낼 카드가 없으면 턴 종료 버튼이 초록
- 지도:
  - 칸을 크게 키우고, 모르는 방은 숨긴다.
  - 갈 수 있는 방은 금빛 테두리로 표시한다.
  - 방 종류는 색 보석으로 표시한다.
  - 지나온 길은 금색 통로다.
  - 주인공 칸을 따라 스크롤된다.
- 모바일:
  - 피해 숫자를 절반 크기로 줄였다.
  - 아래 줄(에너지·연계·뽑기·턴 종료)을 한 줄에 넣었다.
  - 긴 몬스터 이름은 줄을 바꾼다.
  - 대화창을 세로 배치로 바꿨다.
- **새 버전 알림**: 10분마다, 그리고 앱으로 돌아올 때 서버를 확인한다. 새 버전이 있으면 "새 버전이 있어요 · 새로고침" 배너가 뜬다. 세이브는 유지된다.

## 5. 밸런스 (자동 플레이 시뮬레이터)

`scripts/sim.ts`를 실행한다.

```bash
npx esbuild scripts/sim.ts --bundle --platform=node --outfile=/tmp/sim.cjs && node /tmp/sim.cjs 100
```

**봇의 플레이 방식**
- 카드: 한 수 앞을 내다보고 고르는 단순한 방식이다.
- 길: 사람처럼 위로 나아가되, 체력이 낮으면 모닥불, 여유가 있으면 강적·보물을 고른다.

**조정 흐름**
1. 처음엔 승률 3~10%였다. 보스가 벽이었다.
2. 보스 수치를 낮추고 직업 체력을 올렸다. 연계 카드를 넣은 뒤 마법사 시작 덱을 보강했다. 이때 승률은 기사 49%, 마법사 41%, 도적 34%였다.
3. 세로 지도로 바꾸자 지나는 방이 줄어 승률이 다시 낮아졌다. 다음을 조정했다.
   - 모닥불 1개 추가
   - 보스 체력 약 10% 감소
   - 다음 지역으로 갈 때 잃은 체력의 70% 회복
   - 최종 보스 약화
4. 최종 보스 약화 직전 측정: 기사 20%, 마법사 31%, 도적 23%. 최종 보스 약화 뒤에는 아직 다시 재지 않았다.

봇은 단순해서, 사람이 하면 이보다 승률이 높을 것으로 본다.

## 7. 작업 순서 (커밋 요약)

1. React + pixelfx로 로그라이크 덱빌딩 뼈대를 새로 만들었다.
2. 그래픽 방향을 여러 번 바꿨다: 다크 판타지 → 귀여운 치비 → 32비트 고양이 기사 → 최종적으로 밝은 하이비트.
3. 받은 스프라이트 팩을 적용하고, 근접 공격 때 대상까지 돌진하게 했다. 강화 확인 창도 넣었다.
4. 기사·마법사·도적 직업, 카드 등급·레벨, 치명타, 픽셀 피해 숫자, 조준 커서를 넣었다.
5. 탐험 테마로 바꿨다: 지역 6종 중 무작위 3곳, 밝은 배경.
6. 효과음, 적 성향·특수 행동, 밸런스 시뮬레이터를 넣었다.
7. 카드 끌어서 내기, 집을 때 기운, 픽셀 조준 화살표를 만들었다. 피해 숫자를 키우고 타격 템포를 늦췄다.
8. 몬스터 공격·사망 동작을 다양하게 만들고 피격감을 넣었다. 지도를 크고 또렷하게 바꿨다.
9. 공격 이펙트를 다양하게 하고 감속·가속을 넣었다. 물 사제가 화면에서 잘리던 문제를 고쳤다.
10. 직업별 화려한 이펙트(바람 암살자, 물 사제, 기사)를 넣었다.
11. 연계 카드, 스킬별 고유 동작, 기 모으기를 넣었다. 전리품 창이 뜨는 순서를 고쳤다.
12. 코스트 아이콘을 마나 수정으로 바꿨다.
13. 세로 지도, 보스 유물 고르기, 마나의 샘, 상점 유물, 궁극기를 넣고 모바일 화면을 정리했다.
14. 이야기, 졸개 대사, 랜덤 인카운터, 하스스톤식 체력 UI를 넣었다.
15. 새 버전 알림 배너를 넣었다.
